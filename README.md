# CourseDock

A student planner for Feng Chia University. CourseDock is a working name and can be changed in Settings. This is a local development preview.

The app uses an edge-to-edge workspace with a stable scrolling sidebar. Courses & notes and Resources expand directly from their menu buttons. Course pages contain notes, deadlines, schedule, and resources. Notes stay under courses. The overview provides quick capture and recent notes. Deadlines have week/upcoming/calendar/all views and course/completion filters. Resource folders can contain subfolders, with icons, breadcrumbs, rename/move actions, and uploads into the current folder. Only empty folders can be deleted. Sidebar collapse, current folder, and course tab survive refresh. Workspace browser scripts require a disposable browser signed into a test account with a completed profile. Use auth-pages-check.js for unsigned account-route checks.

Run `npm.cmd ci --ignore-scripts`, then `npm.cmd run dev`. Open the address printed by the server. The current preview runs at http://127.0.0.1:5180/. Use the same address and browser profile to reopen your saved workspace.

Courses, Markdown notes, deadlines, weekly meetings, resource links and files, language, and appearance survive refresh using browser storage. Resources support course grouping, added-date sorting, renaming, and downloading. Files are limited to 10 MB each and 100 MB total on this device. Clearing site data removes the local workspace and files. Retain separate copies of important work. Records and files are now separated for each signed-in account in normal app use. Older shared data requires a reviewed import with ownership confirmation. This local namespace is not cross-device sync, encryption, or protection against someone who can inspect browser storage.

The timetable importer reads the supplied one-page MyFCU grid locally. Review and edit extracted classes, then merge or replace the selected semester’s timetable. Exact duplicates are skipped. Other PDF layouts and scanned pages are unsupported. The source PDF is not saved. Course codes and credits must be completed separately. Both timetable and resource uploads accept drag and drop.

The interface includes English/Traditional Chinese, light/dark themes, styled dropdowns, a left-to-right skeleton for loads under three seconds, a spinner for longer loads, and error recovery pages. Footer links open the privacy policy, terms, and data-privacy notice. These notices describe the preview. Operator details and production policies must be completed before public account services launch.

Run `npm.cmd test` for domain/parser checks and `npm.cmd run build` for type checking and a production build. `browser-check.js` is a Playwright CLI run-code script for a fresh test browser with synthetic data. `loading-check.js` verifies delayed loading and injected failures against the Vite preview. Personal PDF test artifacts stay outside Git.

Notes now use a block editor with headings, checklists, tables, code, local images and keyboard reordering. Import UTF-8 Markdown up to 1 MB, or attach PDF/PNG/JPEG up to 10 MB. Old Markdown notes remain readable/editable. The editor omits remote images during import and strips unsafe links. PDFs stay attachments. Settings exports records, canonical note blocks, Markdown copies, imported source Markdown and original files in one ZIP. Missing files stop export. Store the downloaded ZIP securely. Assignments/exams and class meetings support editing without resetting completion or creating duplicates.

`notes-check.js`, `image-check.js` and `planner-edit-check.js` cover these local flows with synthetic records in a disposable browser. `npm.cmd run test:server` runs Convex mock-runtime security tests. `npm.cmd run check:server` checks server types. The profile, course and planner foundation has verified-context ownership checks, validators and transactional read/write budgets. It is installed on a free Convex development project. Dedicated sign-in/sign-up pages connect Clerk development sessions and require the five-input student profile with a server-generated school email before opening the workspace. Successful login opens Overview. The circular sidebar profile photo (initials fallback) opens Edit profile and Log out. Landing-page language/theme selectors persist after refresh and sign-in. Academic records and files still remain in browser storage; signing out does not erase or lock that workspace. See [cloud setup](docs/Cloud-setup.md) for required configuration and endpoint limits.

Academic Convex synchronization, complete account/session/recovery verification, private server uploads, email reminders, account deletion and production security remain unfinished. Development backend functions are installed; no production release claim is made. All six capability areas must be ready before launch.
