## Learning goals

- Use `if` and `else` to choose an action.

## Lecture notes

A variable gives a name to a value. A condition evaluates to `True` or `False`.
In the practice below, the number 60 is only an exercise rule; it is not a university grading policy.

```python
score = 72

if score >= 60:
    print("Practice passed")
else:
    print("Try again")
```

## Trace the program

| Input score | Condition `score >= 60` | Output |
| --- | --- | --- |
| 45 | False | Try again |
| 60 | True | Practice passed |
| 95 | True | Practice passed |
